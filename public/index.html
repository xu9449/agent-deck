      Roles

      A role gives an agent a standing job. Pick one for a task or a pipeline step: its instructions go in front of that step's prompt, and its agent and permission level become the defaults. The defaults are based on public comparisons (Oct 2026): Claude Code for planning, big changes and judging; Codex for building, reviewing and testing at lower cost.

      Answer permission prompts from here

      Claude Code asks a PermissionRequest hook before it shows a permission prompt. Add the hook below to your Claude Code settings and Agent Deck can see every prompt. With Away mode on, you can also allow or deny them here.

      • Away mode off: prompts show in Claude as usual; Agent Deck only lists them.
      • Away mode on: Claude's prompt waits up to ~10 minutes for your answer here, then falls back to its own dialog.
      • Agent Deck not running: the hook fails quietly and Claude asks as usual. Nothing gets stuck.

      Running sessions reload settings on their own. To remove it later, delete this PermissionRequest entry.
